# Coins

O Coins é um jogo de trivia feito em Python.

O jogo tem perguntas de cultura geral e, por cada resposta certa, ganhas moedas. Depois podes usar as moedas na loja para comprar itens que ajudam durante o jogo.

## O que tem

- Perguntas de trivia
- Sistema de moedas
- Loja
- Inventário
- Saltar fases
- Mostrar respostas
- Dicas
- Contador de perguntas certas
